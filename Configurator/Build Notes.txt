## 🖼️ How to add your own icons and background images

This is the best pattern for Qt:

1. Create your image files
   - for example: icon.png, bg.png, check.png

2. Add them to a Qt resource file
   - create a new file like resources.qrc
   - add a prefix such as /images and /icons
   - map the files there

Example structure:

- /images/bg.png
- /icons/generate.png
- /icons/copy.png

Then in the project file add:

- RESOURCES += resources.qrc

3. Use the resources in the UI or stylesheets

For a widget background image:

- setStyleSheet("QWidget#headerWidget { background-image: url(:/images/bg.png); background-repeat: no-repeat; background-position: center; }");

For a button icon:

- button->setIcon(QIcon(":/icons/generate.png"));

For checkbox or radio custom indicators:

- QCheckBox::indicator { image: url(:/icons/checkbox.png); }
- QRadioButton::indicator { image: url(:/icons/radio.png); }

You can do this in Qt Designer or directly in mainwindow.cpp.

> This is the correct way to keep images bundled with the app instead of relying on external file paths.

## 1) Add your own app icon

The app icon is usually set in code:

```cpp
this->setWindowIcon(QIcon(":/icons/app_icon.png"));
```

or if you want it in the project file as a Windows icon:

```pro
RC_ICONS = Doc/Logo.ico
```

That is already in ProFWConfigurator.pro.

If you want to use a PNG in the UI instead of an ICO, use the Qt resource system below.

## 2) Add icons to buttons

This is the easiest pattern:

```cpp
ui->generateButton->setIcon(QIcon(":/icons/generate.png"));
ui->generateButton->setIconSize(QSize(18, 18));

ui->copyButton->setIcon(QIcon(":/icons/copy.png"));
ui->copyButton->setIconSize(QSize(18, 18));

ui->autoNameButton->setIcon(QIcon(":/icons/auto_name.png"));
ui->autoNameButton->setIconSize(QSize(18, 18));
```

Put these in mainwindow.cpp after `ui->setupUi(this);`

## 3) Change checkboxes/radios to custom icons per group

This is the part you were asking for, and it works really well with object names.

For each group box in mainwindow.ui, use the object names already there, such as:

- `printerGroupBox`
- `boardGroupBox`
- `levelingGroupBox`
- `displayGroupBox`
- `thermistorGroupBox`
- `featuresGroupBox`

Then apply a style like this:

```cpp
setStyleSheet(R"(
    QGroupBox#printerGroupBox QCheckBox::indicator {
        image: url(:/icons/printer.png);
        width: 18px;
        height: 18px;
    }

    QGroupBox#boardGroupBox QCheckBox::indicator {
        image: url(:/icons/board.png);
        width: 18px;
        height: 18px;
    }

    QGroupBox#levelingGroupBox QCheckBox::indicator {
        image: url(:/icons/level.png);
        width: 18px;
        height: 18px;
    }

    QGroupBox#displayGroupBox QCheckBox::indicator {
        image: url(:/icons/display.png);
        width: 18px;
        height: 18px;
    }

    QGroupBox#thermistorGroupBox QCheckBox::indicator {
        image: url(:/icons/thermistor.png);
        width: 18px;
        height: 18px;
    }
)");
```

This gives each group its own icon set.

For radio buttons, use:

```css
QGroupBox#printerGroupBox QRadioButton::indicator {
    image: url(:/icons/printer_radio.png);
    width: 18px;
    height: 18px;
}
```

> The important part is `::indicator`. That is the actual checkbox/radio box itself.

## 4) Add a background image to the main window

This is the easiest approach:

```cpp
setStyleSheet(R"(
    QMainWindow {
        background-image: url(:/images/main_bg.png);
        background-repeat: no-repeat;
        background-position: center center;
        background-attachment: fixed;
    }
)");
```

If you want the background only on the central area, use a widget instead of `QMainWindow`:

```cpp
ui->centralwidget->setStyleSheet(R"(
    background-image: url(:/images/main_bg.png);
    background-repeat: no-repeat;
    background-position: center center;
)");
```

## 5) Create a Qt resource file

Create a file like `resources.qrc`:

```xml
<RCC>
  <qresource prefix="/icons">
    <file>icons/app_icon.png</file>
    <file>icons/generate.png</file>
    <file>icons/copy.png</file>
    <file>icons/auto_name.png</file>
    <file>icons/printer.png</file>
    <file>icons/board.png</file>
    <file>icons/level.png</file>
    <file>icons/display.png</file>
    <file>icons/thermistor.png</file>
  </qresource>
  <qresource prefix="/images">
    <file>images/main_bg.png</file>
  </qresource>
</RCC>
```

Then in ProFWConfigurator.pro:

```pro
RESOURCES += resources.qrc
```
